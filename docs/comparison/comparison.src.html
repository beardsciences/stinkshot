Privacy, network and jurisdiction

What each tool sends by default, and who stands behind it.

Only in Stinkshot

  • Find Sensitive Info scans the capture with on-device OCR and proposes redactions for emails, phone numbers, card numbers, IPs, API keys and tokens, and labelled passwords. Snipping Tool covers emails and phones only.
  • Search inside every capture by the text it contains. History is OCR-indexed locally.
  • Snaps to individual UI elements under the cursor, only where they're actually visible, with the wheel to step up to parents.
  • Click and key visualizer in recordings. ShareX highlights the mouse only.
  • Re-editable captures with blur, pixelate and boxes baked into the saved original, so editing later never reveals what you hid.
  • No network at all by default The only network call is an update check that stays off until you turn it on.

Where others are ahead today

  • ShareX has built-in uploads to dozens of services, a much larger effects library, 120 FPS recording, multi-region capture, and Store, Steam and ARM64 builds.
  • FireShot captures full web pages from inside the browser, including frames and scrolling elements. Stinkshot gets there only through scrolling capture of the browser window.
  • Flameshot and Greenshot run on macOS too (Greenshot's Mac app is a separate paid build last updated in 2020).
  • Snipping Tool is already installed on every Windows 11 PC.
  • Stinkshot is pre-release No published installer, code signing or public repository yet, and real-world mileage is days, not years.
